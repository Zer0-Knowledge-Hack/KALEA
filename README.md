# Kalea

Prototipo móvil de intercambio P2P de USDC en Stellar por bolivianos.

Abre `index.html` en un navegador para probar compra, venta, comparación de ofertas y revisión de una orden. El prototipo usa cotizaciones y operadores simulados. El dato del BCB está fechado y se presenta por separado de las ofertas USDC/BOB.

Los recursos de marca y las exploraciones visuales están en `brand/`.
